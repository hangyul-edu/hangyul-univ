**Why this file was added (V18).** Burmese (`my`) has been one of the product's best-covered student
bundles for several passes — including every V17 string — but Myanmar had no market row, so no student
could ever select it. V17 recorded that gap and left it as a commercial decision (§157). The owner
answered it in V18: Myanmar is a market, the canonical list is **33**, and this is its flag.
