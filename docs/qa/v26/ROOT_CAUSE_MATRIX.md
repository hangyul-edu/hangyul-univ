# V26 — Root-cause matrix

Written 2026-10-27, before any V26 product change. It draws on four kinds of evidence:
- a full read of REPORT.md §1–§329 (every audit, gap, hostile-audit, QA-ledger and readiness section);
- the QA logs under `docs/qa/v3…v25`;
- the running stack, captured in `docs/qa/v26/visual/before/`;
- measurements taken on this date (CSS cascade, live database residue).

Section numbers (§) refer to REPORT.md. Each row's last column says what V26 does about it; results are recorded in §341
and §349.

**Severity:** H = a user is misled or blocked, or data or trust is damaged. M = clear friction or debt that users can see.
L = only engineers can see it.
