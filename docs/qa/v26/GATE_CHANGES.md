# V26 — gate changes

Every V26 change to an existing gate, test or skip is listed here. For each one the table records what the gate was for,
why it changed, whether that purpose still holds, where it is protected now, and the controls that show the new check
works:
- **positive control**: the check passes on a correct product.
- **negative control**: the check fails when the defect is put back.

No gate was changed to make a red result green. When an old check stopped matching the code, its purpose was kept and
moved.
