## 56.2 How the work is done today vs. what Hangyul must beat

The stage-by-stage map (lead → graduation, 46 stages) is §3 of the research doc; each stage marks manual copying, re-upload, manual reminders, Excel, chat switching, website searching, missed deadlines and conflicting state. The blueprint (`docs/SERVICE_BLUEPRINT.md`, §57) answers each mark. The ones that shape V9:

| Job | Best current reference | Bar Hangyul must exceed |
|---|---|---|
| "Can I go?" without TOPIK | IDP FastLane (document-free, but "instant offer" without the non-binding label) | Honest routes (language program first / English track / direct) with counts from published requirements, labelled "not an offer" |
| Money | Wise fee display; university guides (payee, refund ladders) | One plan: payee, timing, refundable, basis; money to *show* separate; payment-route guard |
| Agency operations | Agentcis / Meritto pipelines; Excel + KakaoTalk/Zalo | One queue with reasons, seven-value waiting-on, weighted capacity, templates in the student's language, submissions queue |
| University review | Slate Reader (bins, queues, review-and-advance) | Requirement · evidence · status first; review-and-advance; safe bulk incl. select-all-matching |
| University value | Nobody connects admission → CoA → visa → arrival → retention | Partnership evidence with cohorts and denominators, including visa outcomes the MOJ will score |
| Parents | Crimson summaries | Read-only, revocable sponsor view without private content |

**Do not copy** (research §8): unexplained success rates (ApplyBoard 95 %), speed guarantees (Leverage one-day/one-week/one-month), "instant offer" without "not binding", hidden fees, language versions that disagree, AI-written statements, AI credibility scores.
