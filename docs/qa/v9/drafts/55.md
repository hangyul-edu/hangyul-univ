# 55. V9 Independent Final-Service Audit

*2026-10-10, before any V9 code change. Method: REPORT §1–54 and every linked document re-read as a list of claims; the V8 score (87/100) was not inherited. The running system (dev stack, fresh start, dev database as left by V8) was used as each persona; **436 baseline views** were captured with `scripts/qa/v9-capture.mjs` — every routed page as the right persona at 390/1024/1440 (consoles also 768), and the nine key screens at all ten widths 320–1728 — into `docs/qa/v9/before/` with metrics (`metrics.json`). Server answers were checked through the API (`/tmp` helper signing in through Demo access) and the database. Fresh research ran in parallel (§56).*

## 55.1 The question V9 asks

Not "what feature is missing" but "**which job does the user still finish outside Hangyul, or with avoidable work, mistakes or doubt?**" Each finding below names the job, the evidence and the work it still causes.
