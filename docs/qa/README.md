# docs/qa

| Path | What it is |
|---|---|
| [`launch-final/`](launch-final/) | **The only current QA folder.** Results of the final launch pass. |
| `v9/` … `v32/` | Not QA results. A small set of files (86 at the 2026-11-18 cleanup) kept at their original paths because a script, test, data file or source comment reads or cites them there. |

Everything else produced by passes V3–V32 (screenshots, console logs, browser dumps, per-locale records, build
logs, render outputs — 3,707 tracked files) was removed on 2026-11-18; it remains in git history.
